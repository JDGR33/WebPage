Serverless Data Engineering • Infrastructure as Code

⚡ Texas Energy & Weather Serverless Data Lakehouse

View on GitHub ↗

An automated, 100% serverless end-to-end Medallion Data Lakehouse on AWS provisioned with modular Terraform. Ingests hourly ERCOT power grid telemetry (U.S. EIA v2 API) and Houston meteorological observations (Open-Meteo API) to analyze climate-driven grid demand, renewable generation, and battery storage arbitrage across 58,000+ records.

  • Ingestion & Cryptography (Bronze): Daily EventBridge schedules trigger a Python 3.12 AWS Lambda collector that writes immutable raw JSON payloads paired with SHA-256 cryptographic metadata manifests to S3.
  • PySpark ETL & Quality Gate (Silver): AWS Glue 4.0 jobs enforce primary-key deduplication, route malformed records to quarantine prefixes, and write Snappy-compressed Parquet partitioned by year and month.
  • Zero-Crawler Sub-Second Analytics: Uses Amazon Athena Partition Projection over Glue Data Catalog to run Presto/Trino SQL queries in <1 second (scanning 2–416 KB per query) with $0.00/hr idle compute cost.
  • Shift-Left CI/CD: Automated GitHub Actions pipeline running unit tests (unittest), flake8 linting, Lambda artifact packaging, and terraform validate across dev (LocalStack) and prod environments.
